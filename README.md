# nazgob-links

Постоянные адреса для ссылок из модулей. Каждая папка - одна ссылка: страница сразу переводит на адрес из строки
`const TARGET = "..."` в её `index.html`. Чтобы сменить ссылку, достаточно поправить эту строку, модули обновлять не нужно.

| Адрес | Назначение |
|---|---|
| https://jabanazgob.github.io/nazgob-links/discord-relay/ | Модуль Discord Relay (VNDE, Первая настройка) |
